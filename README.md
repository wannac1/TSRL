# TSRL
The official code for paper "[Tutor-Student Reinforcement Learning: A Dynamic Curriculum for Robust Deepfake Detection](https://arxiv.org/pdf/2603.24139)" (CVPR 2026)
![main_archi.pdf](./main_arch.png)

TSRL is implemented within the framework of [DeepfakeBench](https://github.com/SCLBD/DeepfakeBench). The provided code should be placed in the corresponding folders in DeepfakeBench. 

A more comprehensive and refined version of the code, along with detailed usage instructions, will be made available as soon as I got spare time.
